# Bongo Clicker
A script that clicks when you aren't there.

## Useful for?
Though I made it for idling Bongo Cat, there are some other uses for it. All it does is spam the space bar in your terminal, so you can use it for:
- Bongo Cat (duh!)
- Workplace Inactivity Prevention
- Prank script on your friends (set it running when they aren't looking)

## WHAT YOU WILL NEED
You will need a python extension installed. That is called "evdev". It allows systems to overcome the firewall barrier so you can bongo beat even when not there
On Arch-based terminal syntax, run: `sudo pacman -S python-evdev`
On Debain-based terminal syntax, run: `sudo apt install python-evdev`
